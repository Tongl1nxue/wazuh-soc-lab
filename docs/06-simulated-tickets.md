## 具体操作

在项目根目录的 PowerShell 中执行。

```powershell
python scripts/build-lab-tickets.py
```

程序使用 Python 标准库。它会重新校验原始快照 SHA-256、统计、规则验证状态和告警关联；证据不一致时停止生成，避免沿用旧结论。

用记事本或 Markdown 阅读器打开两份工单，检查已执行操作与已知实验是否一致即可，不设问答考核。

11 月 8 日批次尚未执行关闭操作。如果阅读后确认记录准确，可执行：

```powershell
python scripts/build-lab-tickets.py --close-lab
```

该命令表示项目作者已复核这两份授权实验记录，会在本地文件记录“已关闭（模拟工单）”及实际关闭时间。不执行网络阻断、账户修改或外部通知。关闭依据是实验来源已知、检测和复测证据齐全；不是确认发生过生产攻击或生产修复。再次默认运行会保留已关闭状态和原关闭时间；若原始证据变化，需重新生成分析并处理新记录，不会默默沿用已关闭结论。

## 解释：工单与告警的区别

告警是规则匹配结果，一条事件可能关联多条告警。工单负责记录分析员如何使用证据得出结论、做了哪些实际操作以及为什么能够关闭。因此本次 7 条主告警被组织成两份模拟工单，不把 10 条告警直接写成 10 起入侵。

目前两份记录的关闭时间为空，没有把未执行的封禁、密码重置、IPS 阻断或通知发送记为完成。后续 Excel 和周报将读取这些记录的实际状态，而不是预填“已关闭”。
